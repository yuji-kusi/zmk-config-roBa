roBa 保存から書き込みまで

1 回に 1 つだけ押します。絵は画面のおおまかな形で、青い枠が押す場所です。

A. Keymap Editor で保存

1右上の Save を押す

変えたキーが画面に出ているのを確かめてから押します。これで GitHub に変更が送られ、自動でビルドが始まります。

押したあと少し待つと、上の「Latest」の文字が新しくなります。

B. GitHub でビルドを待つ

2GitHub の自分の roBa のページを開く

アドレス: github.com/yuji-kusi/zmk-config-roBa

3上のタブの Actions を押す

4いちばん上の行が緑のチェックになるまで待って、その行を押す

黄色の丸は作業中、緑のチェックは完了、赤のバツは失敗です。数分かかります。

C. ファイルを取る

5下の方の Artifacts にある firmware を押す

zip ファイルがダウンロードフォルダに入ります。

6ダウンロードフォルダの firmware.zip をダブルクリックして開く

中に 3 つのファイルが出てきます。使うのは roBa_R-seeeduino_xiao_ble-zmk.uf2 だけです。

D. 右側に書き込む

7roBa の右側（トラックボール側）を USB ケーブルで Mac につなぐ

配列を変えただけなら、左側とリセット用のファイルは要りません。

8右側のリセットボタンを素早く 2 回押す

または、左親指のかなキー（下の段の左から 4 つ目）を押しながら、右手の N の左隣のキーを押します（解説にある bootloader のキー）。

デスクトップや Finder に XIAO-SENSE というドライブが出れば成功です。

9roBa_R のファイルを XIAO-SENSE にドラッグする

ドライブが消えたら書き込み完了です。Mac がエラーを出しても、書き込みは済んでいるので閉じて大丈夫です。

10ケーブルを抜いて試す

かなキーでかな、英数キーで英数になれば完成です。キーが効かないときは、右側のリセットボタンを 1 回だけ押します。
