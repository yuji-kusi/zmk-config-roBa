## 決まったこと（串田さんの希望）
- 英数とかな: 左親指のいちばん内側を軽く押すたびに入れ替え（Control+Space を送る。MacBook で入れ替わるのを確認済み）。長押しは Command。⌘英かなは MacBook 本体用にそのまま
- 左親指: 外から Esc（長押し Control）／Space（長押し Option）／英かな入れ替え（長押し Command）
- 右親指: 内側 Backspace（長押しで KoeType の音声入力 Command+.）／外側 Enter（長押しで数字と F キーの面）。2 つ同時の長押しで記号と矢印の面
- 右下の角: 軽押し F7、長押しで Mac 操作・メディアの面（デスクトップ切り替え Control+←→、Mission Control、撮影 Shift+Cmd+3/4/0＝CleanShot、音量、Bluetooth、書き込みの準備は / の位置）
- Shift: Z と / の長押し。面の切り替えは右手だけ
- 串田さんは Keymap Editor を使わず、言葉で頼む。こちらが keymap を直接書き換えて push（fork への push は許可済み）
- 問いは 1 回 1 つ、二択、専門用語なし。表は画面（Chrome）に出す

## 確かめること（実機で）
- スペース・Esc を長めに押しても出るか、英かなの入れ替え直後に Command+文字 に化けないか
- Enter を押さえて数字を打つと数字の面になり、Enter が出ないか
- Backspace 長押しで KoeType が 1 回だけ始まるか（押している間に何度も反応しないか）
- 画面の明るさのキー（Mac で効かなければ F14/F15 に変える）
- 書いたのに配列が変わらない場合は ZMK Studio の保存が残っている可能性（Restore Stock Settings か settings_reset）
