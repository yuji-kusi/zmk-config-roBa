roBa 親指と Mac 操作の面（第 5 版・書き込み用に確定）

串田さんの希望のまとめと、動画の配列図 3 枚を土台にしました。まだ書き込んでいません。OK が出たらこの形で書き換えます。

決まったこと：英数とかなは、左親指のいちばん内側のキーを軽く押すたびに入れ替わる（Mac の「前の入力ソースを選択」＝ Control+Space を送る。串田さんの MacBook で入れ替わるのを確認済み。Control+Space はふだん使わないので、この役に回します）。⌘英かなは MacBook 本体のキーボード用にそのまま残します。

2. 親指キー

場所軽く押す長押し
左親指 1（いちばん外）EscControl
左親指 2（真ん中）スペースOption
左親指 3（いちばん内）英数とかなを入れ替えCommand
右親指 1（内側）Backspace音声入力（KoeType の Command+.）
右親指 2（外側）Enter数字と F キーの面
右親指の 2 つを同時に―記号と矢印の面
右下の角（小指）F7（カタカナ変換）Mac 操作・メディアの面

親指は「しっかり長く押したときだけ」長押し扱いにします。右親指の 2 つを同時に押す判定は、ごく短い時間（0.04 秒）に両方押したときだけにして、Backspace と Enter を続けて打っても誤って働かないようにします。

左手の下の段（Z の下の 3 つ）は、外から Control・Command・Tab にします（今は Control・Command・Option）。Shift+Tab は Z を長押ししながら Tab です。

代わりにできなくなること：Backspace を押しっぱなしで続けて消すこと（一度軽く押してすぐ押し直し、押し続ければ続けて消せます）と、スペースの押しっぱなしでの連打。

6. 外すもの・残すもの

今あるものどうするか
左親指の かな・英数（今日入れたもの）、A と S の同時押しの英数外します（英かなは ⌘英かなで Command 単独押しに任せる、という希望のため）
S+D で Tab、D+F で Shift+Tab、L と ' で "、C+V で =外します
F1〜F13 の面、今の矢印の面外します（F1〜F12 は数字の面へ、矢印は記号の面へ）
G の右隣の Shift+Cmd+S（Windows の画面切り取り）外して [ にします。H の左隣の -（長音の「ー」）はそのまま残します。] は記号の面にあります
今の矢印の面の Home・End、タブの切り替え（Control+Tab／Control+Shift+Tab）Home・End は記号の面、タブの切り替えは Mac 操作・メディアの面に移します
今の矢印の面の Command+Shift+←／→（行の頭・終わりまで選ぶ）、F13外します（使っていたら言ってください。置き場所を作ります）
右下の角の Delete記号の面の左親指 2（スペースの位置）に移します
トラックボールを動かした直後の J・K・L クリック、I の長押しでスクロール残します
BetterTouchTool の Notion・Chrome・Finder・デスクトップ1ほぼ使っていないとのことなので置きません
全部の Bluetooth 接続を消すキー外します（誤操作で全部のつなぎ先が消えるため）
