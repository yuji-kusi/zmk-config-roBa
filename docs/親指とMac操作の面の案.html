roBa 親指と Mac 操作の面（第 6 版・今ファイルに入っている設定）

串田さんの希望のまとめと、動画の配列図 3 枚が土台です。点検で直した所（長めに押しても Space・Esc を出す、Enter を短く押して数字を打っても Enter を出さない、危ないキーの位置）まで反映済みです。

英数とかな：左親指のいちばん内側（長押しは Command）のキーを軽く押すたびに入れ替わる（Mac の「前の入力ソースを選択」＝ Control+Space を送る。串田さんの MacBook で入れ替わるのを確認済み。Control+Space はふだん使わないので、この役に回しました）。Command+C のように素早く続けて押したときは Command として働きます。⌘英かなは MacBook 本体のキーボード用にそのまま残します。

左親指の Esc・スペースは「しっかり長く押したときだけ」長押し扱いです。長めに押しても、他のキーを押さずに離せば Esc・スペースが出ます。

Enter と右下の角は、押さえたまま別のキーを押して離すと面に入ります（Enter を短く押して数字を打っても Enter は出ません）。

右親指の 2 つを同時に押す判定は、ごく短い時間（0.04 秒）に両方押したときだけ、しかも直前に他のキーを打っていないときだけです。Backspace と Enter を続けて打っても誤って働きません。

左手の下の段（Z の下の 3 つ）は、外から Control・Command・Tab です（前は Control・Command・Option）。Shift+Tab は Z を長押ししながら Tab です。

代わりにできなくなること：Backspace を押しっぱなしで続けて消すこと（一度軽く押してすぐ押し直し、押し続ければ続けて消せます）と、スペースの押しっぱなしでの連打（こちらも、軽く押してすぐ押し直して押し続ければ連打になります）。

6. 外したもの・残したもの

前にあったものどうしたか
左親指の かな・英数（前に入れたもの）、A と S の同時押しの英数外しました（英かなは左親指のいちばん内側の軽押しで入れ替えるため）
S+D で Tab、D+F で Shift+Tab、L と ' で "、C+V で =外しました
F1〜F13 の面、前の矢印の面外しました（F1〜F12 は数字の面へ、矢印は記号の面へ）
G の右隣の Shift+Cmd+S（Windows の画面切り取り）外して [ にしました。H の左隣の -（長音の「ー」）はそのまま残しました。] は記号の面にあります
前の矢印の面の Home・End、タブの切り替え（Control+Tab／Control+Shift+Tab）Home・End は記号の面、タブの切り替えは Mac 操作・メディアの面に移しました
前の矢印の面の Command+Shift+←／→（行の頭・終わりまで選ぶ）、F13外しました（使っていたら言ってください。置き場所を作ります）
右下の角の Delete記号の面の左親指 2（スペースの位置）に移しました
トラックボールを動かした直後の J・K・L クリック、I の長押しでスクロール残しました
BetterTouchTool の Notion・Chrome・Finder・デスクトップ1ほぼ使っていないとのことなので置いていません
全部の Bluetooth 接続を消すキー外しました（誤操作で全部のつなぎ先が消えるため）
