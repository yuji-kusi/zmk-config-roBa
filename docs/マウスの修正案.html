右下の角

右親指で Enter を押さえ、左小指で A の位置を長押し（Shift）、右手の H J K L で選ぶ範囲を広げます。軽く押せばいつもの # です。ほかの記号はそのまま（絵では省いています）。

困る所
・A の位置の長押しは 0.25 秒押さえてから働きます（ふだんの面の A と同じ設定）。素早く押すと # が出ます。
・ボールに触った直後の 1.5 秒は、J と K で文字が打てません（今は 0.7 秒）。
・J を押さえている間はゆっくりなので、長い文章を一気に選ぶときも遅くなります。そのときは、選び始めをクリックしてから A（長押しで Shift）を押さえて終わりをクリックすると一気に選べます（今の配列でもできます）。
・クリックを押したままにするキー（ドラッグ固定）は、離し忘れると困るので入れていません。
作れるか：ボールを遅くする仕組みは、今使っているボールの部品（kumamuk-git/zmk-pmw3610-driver）に入っていることを確かめました。今まで使っていなかった機能なので、書き込んだら実機で確かめます。

アプリ切り替えの専用キー（取りやめ。下は検討したときの記録）

動き：1 回押すと Command+Tab（切り替えの一覧が出て、一つ前のアプリが選ばれる）。続けて押すと次のアプリへ進む。ほかのキーを押すか、0.8 秒何も押さなければ確定（Command を離したことになる）。Command を押さえ続ける必要はありません。
作れるか：ZMK 本体には無い仕組みなので、部品を 1 つ足します（dhruvinsh/zmk-tri-state。ZMK の swapper／tri-state をそのまま実装したもの。最終更新 2025 年 3 月）。中身を読んで、今の ZMK（v0.3）の作りと合うことは確かめました。最後はビルドが通るかで確かめます。待ち時間 0.8 秒は変えられます。

取りやめた理由（第 31 版で試して分かったこと）：切り替えのあいだ Command を押したままにするので、少し長いとチートシートが出る。さらに左親指の Command と重なると Command が押されたまま残り、A で全選択になるなど操作できなくなった。第 32 版で G の右隣を Mission Control に、X の真下を数字の面だけに戻し、部品も外しました。アプリの切り替えは、左親指の Command を軽く押してから Tab（一つ前のアプリへ）。

B の右隣（取り消し・やり直し）は使わない。

空いているキーの一覧

キー今の役空きと言える理由一押しで使えるか
X の真下（おすすめ）・左手押さえている間 数字と F キーの面同じ面に右親指の delete の長押しでも入れる（入り口が 2 つある）使える
N の左隣の軽押し・右手B（長押しは音声入力）B は左手にもある使える
右下の角の軽押し・右手前方削除（長押しはスクロール）前方削除は記号と矢印の面（Enter を押さえて Space の位置）にもある使える
数字と F キーの面の T・G・G の右隣・B・B の右隣・- の位置何もなし本当の空き×（面に入るキーと 2 本指）
Mac 操作の面の Q・G の右隣・Z何もなし本当の空き×（Z の真下と 2 本指）

ふだんの面には、何も入っていないキーはありません。「同じことが別のキーでもできる」所が実質の空きです。

おすすめ：X の真下。左手で一押し、Mission Control と同じ左手にまとまります。困る所は、数字と F キーの面へ入るのが右親指の delete の長押しだけになること（Command+数字 は、左親指の Command を軽く押してから delete を長押しして数字）。
