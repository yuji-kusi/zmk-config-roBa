# お手本メモ（roBa のキー配列を自分で変えるとき）

串田さん用の要点メモ。元の解説・動画の丸写しではなく、要点だけをまとめた。案内はこのメモの言い方と順番に合わせる。

## お手本 1: sensai-gadget「Keymap Editor の使い方」
https://sensai-gadget.com/keymap-editor-usage/

- 画面の上のタブ: LAYERS（キー配列）／ CONDITIONAL LAYERS ／ COMBOS（同時押し）／ MACROS ／ BEHAVIORS
- キーの変え方は 3 段: ①LAYERS でキーの四角を押す → ②Behavior（動きの種類）を選ぶ → ③パラメーター（送るキーや面の番号）を選ぶ
- よく使う Behavior
  - `&kp` 普通のキー
  - `&mo` 押している間だけ別の面へ
  - `&tog` 面をオン・オフ
  - `&to` その面へ切り替え
  - `&lt` 長押しで別の面、軽押しでキー
  - `&mt` 長押しと軽押しで別のキー（例: 長押しでコマンド、軽押しで F）
  - `&trans` 下の面と同じ
  - `&none` 何もしない
- レイヤー 0 がいつもの面。よく使うキーは 0 に置く
- `&bootloader` はリセットボタン二度押しと同じ（書き込み待ちにする）。`&sys_reset` は一度押しと同じ
- ZMK Studio を使えば書き込みなしで変えられるが、割り当てられない動きもある
- 保存・ビルド・ファイル取り出し・書き込みは、このページには書かれていない → roBa 組み立てガイド「5. ファームウェアの書込み」で補う

## お手本 2: YouTube「分割キーボード入門」
https://www.youtube.com/watch?v=Ls5FmNoLLws

- レイヤーはシフトの仲間。あるキーを押している間だけ、ほかのキーの中身が数字や記号に変わる
- 目的は「手をホームの位置から動かさない」こと
- 親指キーは、軽押しでスペースやエンター、長押しでレイヤー
- ホームの段の長押しで修飾キー（例: F の長押しでコマンド、S の長押しでコマンド＋シフト）。⌘T・⌘W が手を動かさずに打てる
- 記号は左右で対に並べると覚えやすい
- 慣れるまで 1 か月ほどかかる。設定は使いながら少しずつ詰める

## roBa での対応
- 書き込むのは右側（トラックボール側）だけでよい（配列だけ変えたとき）
- roBa の `&bootloader`: 左親指のかなキー（下の段の左から 4 つ目）を押しながら、右手の N の左隣のキー
- 英かな: 下の段の左から 4 つ目＝かな（LANG1）、6 つ目＝英数（LANG2）。⌘英かなとはぶつからない
- トラックボールを動かすと J＝左クリック、K＝中クリック、L＝右クリック（止めてから 0.7 秒以内）。I を押しながら転がすとスクロール
