数字は右手（U・I・O の段が 7 8 9、J・K・L が 4 5 6、M・カンマ・ピリオドが 1 2 3、N が 0）。F キーは左手（Q から順に F1〜F4、A から F5〜F8、Z から F9〜F12）。

推奨の理由：数字を打つ右手と反対の、左親指で面に入るのがいちばん打ちやすいからです。Space は「しっかり長く押したとき」だけ面に入ります。文章を速く打っているときは Space のままです。

そのぶん Option は右親指の外側（Backspace）の長押しに移します。デスクトップの切り替え（Option＋数字）は、右親指で Option を押さえ、左親指で数字の面に入って、右手で数字です。

Esc の場所

キー軽く押す長押し
C の真下EscMac 操作の面

X の真下は Command、Z の真下は Control のまま。前に C の真下にあった Tab は、左親指 1 に移りました。

Command+Tab と Command+Space は、X の真下の Command を押さえて、左親指 1 を軽く押します（左親指 1 は Tab と Command が同じキーのため）。

Esc は少し長めに押しても、他のキーを押さずに離せば Esc が出ます。

記号の面では、押さえている右小指の列（P・'・/ の位置）は使いにくいので、$ と % は Y と U の位置に移しました。

同時押しや「押さえたまま別の親指」は全部やめました。どの面も、キー 1 つの長押しだけで入ります。
