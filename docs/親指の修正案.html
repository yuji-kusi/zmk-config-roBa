roBa 親指の修正案

左親指（外から）

場所軽く押す長押し
1（いちばん外）なし前は EscCommand前は Control
2（真ん中）Space（そのまま）Option（そのまま）
3（いちばん内）英数とかなの入れ替え（そのまま）Control前は Command

いちばん外は Command だけにします。軽押しの役が無いので、押した瞬間から Command になり、Command+C などが遅れません。

Space は真ん中のまま（推奨）。親指をいちばん自然に置ける所で、いちばんよく使うキーだからです。

Esc の新しい場所

場所今修正案
左手の下の段（Tab の外隣）CommandEsc

左手の下の段は外から Control・Esc・Tab になります。Command は親指にあるので、ここの Command は Esc に回します（推奨）。

右親指

場所軽く押す長押し
内側Enter前は Backspace音声入力（KoeType。そのまま）
外側Backspace前は Enter数字と F キーの面（そのまま）
記号と矢印の面―外側を押さえたまま、内側を押す前は 2 つを同時に長押し
右下の角F7（そのまま）Mac 操作の面（そのまま）

長押しは「内側＝音声入力、外側＝数字と F キーの面」で合っています（推奨。音声入力はこのまま内側）。

同時押しは、ほぼ同時（0.04 秒以内）に押さないと効かず、外れやすいのでやめます。代わりに「外側で数字の面に入って、そのまま内側を押すと記号の面」にします（推奨）。順番に押せばよいので失敗しにくく、Enter と Backspace を続けて打っても誤って働きません。

Backspace を押し続けて消したいときは、一度軽く押してすぐ押し直し、そのまま押し続けます。Enter も同じです。
