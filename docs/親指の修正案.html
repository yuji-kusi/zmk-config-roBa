このキーボードの使い方

  1. 「面」は、キーの中身をまるごと入れ替える仕組みです。決まったキーを長押ししている間だけ、数字・矢印・記号などに切り替わり、離すと元に戻ります。
  2. 面に入るキーは、中身を打つ手と反対の手の親指です（数字と矢印は右手で打つので左親指、記号は左手で打つので右親指）。
  3. 「Mac 操作の面」は、画面の明るさ・音量・音楽の再生・デスクトップの切り替え・画面の撮影・Bluetooth のつなぎ先など、ふだんはトラックパッドや F キーでやる Mac の操作をまとめた面です。
  4. トラックボールを動かすと、しばらくの間 J が左クリック、K がホイールクリック、L が右クリックになります。I を押さえたままボールを転がすとスクロールです。

面の切り替え（どの親指を長押し → 何の面、中身はどちらの手）

長押しするキー入る面中身を打つ手
左親指 2（Space）数字と F キー数字は右手（F キーは左手）
左親指 3（英かな）矢印・Home・End・ページ送り・Delete右手（左手のホームの段で Control・Option・Command・Shift を足せる）
右親指 2（Backspace）記号左手
右下の角（小指）Mac 操作両手（めったに使わないので例外）
（長押しなし）ボールを動かすマウス右手（J・K・L）

同時押しは使いません。どの面も、キー 1 つの長押しだけで入ります。

親指のキー（左から順に）

キー軽く押す長押し
左親指 1（いちばん外）TabCommand
左親指 2（真ん中）Space数字と F キーの面
左親指 3（いちばん内）英数とかなの入れ替え矢印の面
右親指 1（内側）Enter音声入力
右親指 2（外側）Backspace記号の面
右下の角（小指）F7Mac 操作の面

文字キーの真下の 3 つ

キー軽く押す長押し
Z の真下Control（押している間）
X の真下Tab（Command+Tab は左親指 1 を押さえてここ）
C の真下EscOption

前の希望から変わった点：「左親指 3 つの長押し＝Control・Option・Command」ではなくなりました。左親指の長押しは Command・数字の面・矢印の面です。

親指の長押しが面の切り替えに変わったぶん、Control は Z の真下、Option は C の真下の長押しに移しました。
