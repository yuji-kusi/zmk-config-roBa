大文字の打ち方（roBa の Shift）

  • 右手の文字（J K L I N H など）の大文字：左の A を長押し（Shift）したまま押す。
  • 左手の文字（X T F G B など）の大文字：右の ' を長押し（Shift）したまま押す。A の Shift は反対の手のキーにしか効かないためです。
  • 一呼吸おく：文字を打った直後 0.15 秒以内は、Enter・delete・' などを押さえても長押しにならず、Enter などがそのまま出ます。g$・gT・G のように続けて押すときは、g の後に一呼吸おいてから押さえてください（すぐだとリンクが開いたりします）。

Vimium の今の設定（読み取った内容）

  • 自分で割り当てたキー：h 戻る、l 進む、i リンクに文字を出す、I リンクを新しいタブで開く。
  • 注意：i をリンク用にしているので、Vimium の「入力モード（i）」は使えません。文字の入力欄へは gi で移れます。
  • Vimium が止まるサイト：寿司打（sushida.net のプレイ画面）と edclub のタイピング画面は Vimium が全部止まる。
  • キーをサイトに渡すサイト：Gmail は j・k、Udemy は a・s・d・f、YouTube は a・s・d・f・x・z（YouTube では f・d・x、Udemy では f・d が Vimium として働かない）。
  • そのほか：リンクの文字の色はダーク系の自作の見た目。新しいタブは Chrome の新しいタブのページ。ほかは初期設定のまま。
