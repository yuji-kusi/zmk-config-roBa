Delete
・消す向きと手をそろえました：左親指で Backspace（左を消す）、右親指で Delete（右を消す）。Enter は右親指の内側。
・英かなの入れ替えは左親指のいちばん外（長押しは Command）。Space は真ん中のまま。Tab は X の真下。
・面の切り替え：左親指の Space の長押しで数字、Backspace の長押しで矢印、右親指の Delete の長押しで記号。
・Mac 操作の面は、右手の N の左隣（;）を長押し。中身はおもに左手で打ちます（反対の手で切り替え）。
・Z の真下は Esc に。X の真下は Tab（長押し Control）、C の真下は Esc（長押し Option）。
・右下の角は Delete。F7 は数字と F キーの面にあります。I を押さえてボールを転がすとスクロール（元のまま）。
・記号の面は、動画の Layer 2 の並びに合わせました。
