前方削除（初期設定のまま）
・delete＝カーソルの左を消す（Mac の delete キー）。前方削除＝カーソルの右を消す（Mac の fn+delete）。
・左親指：中央寄り（斜めのキー）から「delete／長押し Control」「Space／長押し Option」「Tab／長押し Command」。
・右親指：中央寄りから「前方削除／長押しで記号と矢印の面」「Enter／長押しで音声入力」。
・左手の下の段：Z の真下は押さえている間 Mac 操作の面、X の真下は Esc（長押しで数字と F キーの面）、C の真下は英かなの入れ替え。
・音声入力は、右親指の前方削除のすぐ上のキー（N の左隣、; のキー）の長押しに移しました（実物の位置で確認済み。紫の枠）。誤って始まらないよう 0.3 秒。
・Enter の長押しは Shift+Command（推奨）。Enter を押さえて Z でやり直し、T で画面の文字を写し取る、など。打った直後は必ず Enter、長押しして何も打たずに離しても Enter は出ません（誤って送信しない）。
・Shift は A と、L の隣（'）の長押し（Z と / は普通の文字だけに）。誤って Shift にならない工夫：文字を打った直後 0.15 秒以内は必ず文字、0.25 秒押さえたうえで反対の手のキーを押したときだけ Shift。注意：Shift を付けたい文字は、反対の手の Shift で打つ（左手の文字は右の ' 、右手の文字は左の A）。右の Shift は L の右隣（' のキー）で、音声入力の ; とは別のキーです。
・右下の角は初期設定のまま前方削除。I を押さえてボールを転がすとスクロール。
